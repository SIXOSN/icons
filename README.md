# icons

用于 mihomo 代理组与 OpenClash 控制面板的公开 SVG 图标仓库。

## Andrews & Arnold

原始图标：[aa-support.svg](aa-support.svg)。

在对应代理组中设置：

```yaml
icon: https://raw.githubusercontent.com/SIXOSN/icons/main/aa-support.svg
```

本仓库保持公开，因此即使分流规则所在的 `SIXOSN/rules` 仓库设为私有，图标仍可匿名下载。控制面板需要支持代理组的 `icon` 字段，例如 Zashboard。

此图标由用户提供，保持原始 SVG 内容。对应品牌标识的权利属于其权利人。
